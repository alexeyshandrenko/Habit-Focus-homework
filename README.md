# Habit Focus — домашнее задание (занятие 1)

Одноэкранный трекер привычек на React: одна привычка в фокусе, галочка за сегодня, streak, `localStorage`.

## Запуск

```bash
cd app
npm install
npm run dev
```

Откройте URL из терминала — обычно http://localhost:5173/

```bash
cd app
npm run build          # production-сборка
npm run lint           # oxlint
node scripts/smoke-domain.mjs   # смоук правил дат/streak/имён
```

Наивный прогон (без спеки): откройте `docs/naive/index.html` в браузере.

## Что сделано

- Спецификация `SPEC.md` и Часть II `AGENTS.md`
- Наивный прогон в `docs/naive/`

- Дизайн-проход и скриншоты до/после: `docs/screenshots/`

## Сравнение наивного и основного прогона

| | Наивный (`docs/naive`) | По спеке (`app/`) |
|---|---|---|
| UI | список сразу | одна привычка + стрелки/select |
| Streak | нет | есть |
| Дубли имён | разрешены | блокируются |
| Битый JSON | `JSON.parse` может уронить скрипт | сброс в пустое состояние |
| Стек | один HTML | React 19 + Vite 8 + TS |
