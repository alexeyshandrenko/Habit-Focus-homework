## Размышления

- Тема: **трекер привычек** — уместен под дедлайн и frontend-вектор ДЗ.
- A.1 / B.3 / streak=да зафиксированы в SPEC; переключение — стрелки + select.
- Наивный прогон сделан отдельно (`docs/naive`): один HTML, список, без защит — чтобы было с чем сравнить.
- Основной прогон в `app/`: доменная логика вынесена из UI (`domain.ts` / `storage.ts`), чтобы дубли, будущее и битый JSON не зависели от «счастливого» рендера.
- Скриншоты 360/1440 и дизайн-проход ещё не делали — по правилам Части II дизайн лучше отдельным этапом; иначе смешается с логикой.
- Смоук `scripts/smoke-domain.mjs` дублирует правила дат/streak упрощённо (не импортирует Vite-модули из‑за ESM-расширений) — это компромисс, не замена UI-проверки.
