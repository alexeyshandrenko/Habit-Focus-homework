# Скриншоты дизайн-прохода

Одинаковые данные: `http://localhost:5173/?demo=1` (5 демо-привычек).

| | 360 | 1440 |
|---|---|---|
| До | `before/360.png` | `before/1440.png` |
| После | `after/360.png` | `after/1440.png` |

Съёмка: `cd app && node scripts/screenshots.mjs before|after` (нужен запущенный `npm run dev`).

Что изменилось визуально: типографика Syne/Outfit, сильнее бренд, фон с орбами, streak-бейдж, кнопки не pill, motion при смене привычки и отметке.
