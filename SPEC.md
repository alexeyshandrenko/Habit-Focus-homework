# Спецификация

## Что делаем

Одноэкранный трекер привычек на React: в фокусе одна привычка, её можно отметить за сегодня галочкой, видеть серию дней (streak), переключаться между привычками и управлять списком (добавить / переименовать / удалить).

## Для кого и зачем

Типичный пользователь, который хочет не забывать ежедневные привычки: быстро увидеть «сегодняшнюю» привычку, отметить выполнение и не потерять прогресс после перезагрузки страницы.

## Сценарии

1. **Первый заход.** Пользователь видит пустой экран и CTA «Добавить». Создаёт первую привычку — она становится активной в фокусе.
2. **Отметить сегодня.** На активной привычке ставит галочку «сделано сегодня». Данные сохраняются; после перезагрузки галочка и streak на месте.
3. **Снять отметку.** Повторный клик по галочке за сегодня снимает выполнение; streak пересчитывается.
4. **Переключение.** Пользователь листает привычки (назад / вперёд или выбор из списка) — на экране по-прежнему одна активная.
5. **Демо-данные.** С пустого экрана может нажать «Заполнить пример» и получить 5 привычек для проверки состояний.
6. **Переименовать / удалить.** Меняет имя или удаляет привычку; после удаления фокус переходит на соседнюю или на пустой экран, если привычек не осталось.
7. **Дубль имени.** Пытается создать или переименовать в имя, которое уже есть (без учёта регистра и крайних пробелов) — получает понятную ошибку, список не меняется.
8. **Будущая дата.** Отметить день в будущем нельзя — операция отклоняется с понятным сообщением (даже если дату передали не через UI).
9. **Битые данные.** В `localStorage` лежит испорченный или чужой JSON — экран не падает, состояние сбрасывается в пустое, показывается пустой экран с CTA.

## Состояния

| Состояние | Что видит пользователь |
|---|---|
| **Пусто** | Нет привычек. Заголовок/бренд экрана, короткий текст, CTA «Добавить», опционально «Заполнить пример». |
| **Есть данные** | Одна активная привычка: имя, галочка за сегодня, текущий streak (число дней подряд). Есть навигация по привычкам и действия добавить / переименовать / удалить. Для демо — не меньше 5 привычек через «Заполнить пример». |
| **Ошибка** | Некрашащий UX: сообщение при дубле имени; при попытке отметить будущее; при сбросе после битого `localStorage` — возврат в «Пусто» (без белого экрана и без исключения в консоли, ломающего UI). |

## Чего точно не делаем

- Аккаунты, авторизация, синхронизация между устройствами
- Бэкенд, база данных, внешние API
- Push / email-напоминания
- Календарь на месяц и произвольный выбор прошлых дат в UI (только «сегодня» + отображение streak)
- Графики, статистика за периоды, экспорт
- Массовые действия и экран-список как основной режим (список — только для переключения)
- PWA, офлайн-сервис-воркеры, мобильные сторы

## Допущения

- **Стек:** React + Vite, клиент только в браузере — быстро собрать и проверить под дедлайн курса.
- **Хранение:** один ключ в `localStorage`; схема версионируется полем `version`. Битый/чужой JSON → сброс в пустое состояние.
- **«Сегодня»:** локальная дата браузера (`YYYY-MM-DD`), без таймзон-сервисов.
- **Streak:** число подряд идущих дней с отметкой, считая от сегодня назад (если сегодня не отмечено — от вчера). Пропуск дня обнуляет серию.
- **Галочка за сегодня:** одно значение на день; повторный клик переключает (on/off), двух записей за день не бывает.
- **Уникальность имени:** сравнение после `trim` и без учёта регистра.
- **Демо:** ровно 5 привычек создаёт только действие «Заполнить пример», чтобы состояние «Пусто» оставалось достижимым из UI.
- **Адаптив:** обязательные ширины проверки — 360px и 1440px.

## Открытые вопросы

| Вопрос | Ответ |
|---|---|
| Для кого? | Типичный пользователь, который хочет не забывать привычки |
| Одна привычка или список? | На экране одна; переключение между несколькими (вариант A.1) |
| Как отмечать? | Галочка за сегодня |
| Streak? | Делаем |
| CRUD привычек? | Добавить / удалить / переименовать |

## Критерии приёмки

- [ ] Пустой экран: нет привычек, виден CTA «Добавить»
- [ ] Можно добавить, переименовать и удалить привычку
- [ ] На экране в фокусе одна привычка; между привычками можно переключиться
- [ ] Галочка «сегодня» сохраняется после перезагрузки страницы
- [ ] Повторный клик по галочке снимает отметку; за один день не две записи
- [ ] Отображается текущий streak и он пересчитывается после отметки / снятия / «пропущенного» дня в данных
- [ ] Нельзя сохранить привычку с именем-дублем (trim, без регистра) — есть сообщение об ошибке
- [ ] Нельзя отметить дату в будущем — есть сообщение об ошибке
- [ ] Битый JSON в `localStorage` → пустой экран без краша
- [ ] «Заполнить пример» даёт 5 привычек
- [ ] Ширины 360 и 1440: без горизонтального скролла, элементы не наезжают друг на друга
- [ ] Клавиатура: Tab обходит интерактивные элементы, фокус виден, Enter/Space активируют галочку и основные кнопки
