# Habit Focus

Трекер привычек: одна привычка в фокусе, галочка за сегодня, streak, localStorage.

## Запуск

```bash
cd app
npm install
npm run dev
```

Откройте URL из терминала (обычно http://localhost:5173).

```bash
npm run build   # проверка сборки
npm run lint    # oxlint
```

Спецификация и правила — в корне репозитория: `SPEC.md`, `AGENTS.md`.
